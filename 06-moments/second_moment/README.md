# Second Moment Sketch

Реализуйте алгоритм подсчета второго момента.

## Второй момент

Второй момент (F2) определяется как сумма квадратов числа вхождений элементов.

## Алгоритм

* Выбирается 4-универсальная хэш-функция h, отображающая элементв в {-1, +1}.
* Чтобы сгенерировать такую хэш-функцию, можно выбрать 4 случайных числа a0, a1, a2, a3 (от 0 до p - 1) и определить h(x) как `a0 + a1 * x + a2 * x^2 + a3 * x^3 ` по модулю `p`. После этого можно просто посмотреть на четность h(x). Обратите внимание, что в такой постановке четные значения будут чуть более вероятны, чем нечетные. Этим можно или пренебречь (при больших p), или придумать механизм, как сделать эти вероятности равными.
* Дальше вычисляется T как сумма h(x) по всем элементам.
* Значение T^2 является оценкой второго момента.
