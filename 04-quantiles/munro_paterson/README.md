# Munro Paterson

Реализуйте алгоритм поиска k-й порядковой статистики за несколько проходов.

## Верхнеуровневый алгоритм

Алгоритм состоит из нескольких проходов. Проход выглядит следующим образом:
* строится структура данных, позволяющая для некоторых элементов понять их примерные позиции. В данную структуру скармливаются только те значения, которые находятся в диапазоне ответа (см. следующий пункт).  
* происходит запрос со значением k к структуре данных. В ответ ожидается ограничение снизу и ограничение сверху на значение k-й порядковой статистики.
* k адаптируется таким образом, чтобы не учитывать элементы, которые больше не попадают в потенциальный диапазон ответа.

Алгоритм прекращается, когда нижняя и верхняя оценки на ответ совпадают.

Изучите класс `KthFinder` в тесте. Он реализует логику вида "Скармливать только в скетч нужные значения и подбирать параметр k под новый проход".

От Вас требуется лишь построить структуру данных, в которую за один проход скармливаются значения, после чего структура должна вернуть ограничения на k-ю порядковую статистику (среди тех значений, что скормили в структуру).

## Munro Paterson Sketch

Наполнение элементами выглядит следующим образом:
* предлагается мысленно разбить поток данных на блоки размера sz;
* на данных блоках мысленно строится дерево;
* промежуточная вершина представляет из себя объединение массивов детей, из которого выкинули элементы с нечетными индексами (индексация с единицы);
* чтобы дерево оказалось полностью заполненным, в структуре есть метод `Finalize()` - в нем следует докинуть в структуру фиктивные бесконечные значения.

В результате в корне хранится sz значений. Для каждого из значений можно найти оценку снизу и сверху на его ранг (Вам предлагается подглядеть эти оценки в оригинальной статье).

Далее следует запрос "по элементу k найти оценку снизу и сверху на значение k-й порядковой статистики". Обратите внимание, что ваша структура для элемента на какой-то позиции выдает ограничения на его ранг, а вам по сути нужно решить обратную задачу. Формулы также можно подглядеть в оригинальной статье.
