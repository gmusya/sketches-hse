# Misra-Gries

Алгоритм Misra-Gries - один из первых стриминговых алгоритмов, предложен аж в 1982 году.
При помощи этого алгоритма Вам предстоит решить задачу поиска k самых частых значений.

## Требования к решению

* дана последовательность размера `n` и параметр `k`;
* найдите `k` элементов, таких что все элементы, встретившиеся хотя бы `n / k` раз присутствуют в результате;
* также в результате могут быть возвращены какие-то другие элементы.

## Относительная погрешность

Также алгоритм Misra-Gries позволяет находить число вхождений элемента в последовательность с относительной погрешностью `1 / k`.
