# Count-Min Sketch

Count-Min Sketch - структура данных для оценки числа вхождений элемента в массив.
В некотором смысле можно считать структуру данных обобщением фильтра Блума.

## Алгоритм

* заведите n массивов размера w;
* зафиксируйте n хэш-функций `h1`, `h2`, ..., `hn`
* при добавлении `x` в `i`-м массиве увеличивайте счетчик `hi(x)`
* число вхождений элемента оценивайте как минимум по счетчикам для данного элемента;

## Подбор параметров

Для получения относительной погрешности `eps` с вероятностью ошибки не больше `delta` достаточно взять `w = e / eps` и `n = log(1 / delta)`. Доказательство этого факта является несложным упражнением. 

## Линейность

Подумайте, как имея Count-Min Sketch от двух разных массивов получить Count-Min Sketch от объединения данных массивов.
