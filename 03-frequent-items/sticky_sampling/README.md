# Sticky Sampling

## Решаемая задача

Алгоритм Sticky Sampling по данным `s, eps, n` с вероятностью `1 - delta` находит такие элементы, что:
* все элементы, встречающиеся хотя бы `s * n` раз, попадут в ответ.
* все возвращенные элементы встречаются хотя бы `(s - eps) * n` раз;

*Замечание*. Подумайте, как свести эту задачу к тому, что умеет решать Misra-Gries.

## Реализация

Реализацию предлагается найти в секции 4.1 статьи [Manku, Gurmeet Singh, and Rajeev Motwani. "Approximate frequency counts over data streams."](https://www.vldb.org/conf/2002/S10P03.pdf)
