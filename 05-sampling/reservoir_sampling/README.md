# Reservoir Sampling

Реализуйте алгоритм Reservoir Sampling для выбора случайной подвыборки фиксированного размера из потока данных.

## Задача

Дан поток из n элементов. Необходимо выбрать ровно k из них таким образом, чтобы каждый элемент оказался в выборке с одинаковой вероятностью k/n.
Помимо этого, каждое подмножество должно иметь одинаковую вероятность оказаться результатом.

## Состояние

В качестве состояния предлагается хранить k элементов (которые являются ответом на текущий момент) и общее число обработанных элементов.
