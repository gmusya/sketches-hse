# Distinct Count

Реализуйте алгоритм для подсчета числа уникальных значений.

## Требования к решению

Ваше решение должно удовлетворять следующим логичным свойствам:
* добавление дубля не должно влиять на состояние алгоритма;
* сериализация с последующей десериализацией не должно повлиять на состояние алгоритма;

Не подгоняйте свое решение под тесты.
* не пользуйтесь тем, что данные генерируются каким-то конкретным образом;
* потребляйте памяти не больше, чем позволяют параметры (разрешается превышать на константу для хранения каких-нибудь метаданных)

## Выбор алгоритма

Гарантируется, что данную задачу можно сдать с помощью скетча KMV (K-th Minimum Value).

С большой вероятностью, алгоритм Flajolet Martin (1985) тоже работает. На занятии разбиралась его версия с одним счетчиком, в оригинальной статье можете найти, как получить точность лучше, используя больше памяти.

Ссылки на конкретные алгоритмы не предоставляются: подразумевается, что при возникновении проблем Вы должны быть способны нагуглить алгоритм.

## Примечание

Если Вы реализовали какой-то адекватный алгоритм, но он не проходит тесты (потому что тесты оказались заточенными под какой-то конкретный алгоритм), то напишите об этом. В таком случае ослаблю тесты, чтобы допустить и другую реализацию.
